## ⚡ Architecture & Tech Stack

| Category | Technology |
|---|---|
| **Framework** | [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) |
| **Styling** | [Tailwind CSS v4](https://tailwindcss.com/) with Custom Obsidian Themes |
| **Animation** | [Motion (Framer Motion)](https://motion.dev/) |
| **Build Tool** | [Vite 6](https://vitejs.dev/) |
| **Icons** | [Lucide React](https://lucide.dev/) |
| **AI Assistant** | Hybrid: [Google GenAI SDK](https://github.com/google-gemini/generative-ai-js) + Intelligent Offline Fallback Engine |
| **Deployment** | Automated CI/CD via GitHub Actions to GitHub Pages |

## 🚀 Key Highlights & Interactive Features

- **Fluid Custom Physics Cursor**: Spring-interpolated cursor with dynamic hover scale and mix-blend differences.
- **Top Spring Scroll Progress Indicator**: Glowing cyan gradient progress bar with recurring wave shimmer.
- **Floating Vertical Navigation Rail**: Persistent minimal navigation rail with shared sliding indicator dot and smooth section transitions.
- **Interactive Playground (Project Showcase)**:
  - Dynamic 3D tilt & glass flare on hover.
  - Full-screen modal case study breakdowns: *The Problem*, *The Solution*, *Tech Stack*, and *Impact*.
- **Logical Architecture (Skill Galaxy)**: Categorized competency matrix across Design, Frontend, Backend, Logic, and Multimedia Production.
- **Interactive Virtual Collaborator (AI Assistant)**: Floating AI collaborator that answers questions about Alvin's background, projects, and skills with hybrid online/offline fallback.
- **Obsidian Dark / Light Theme Toggle**: Persistent theme switcher with spring animations.
